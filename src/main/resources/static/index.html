🎬 빠른 시작 가이드

1단계: 라이브 방송 생성

• 라이브 방송 관리 페이지에서 새 방송 생성

• 호스트 정보와 방송 제목 입력


2단계: 방송 시작

• 생성된 방송을 "방송 시작" 버튼으로 시작

• 상태가 "LIVE"로 변경됨


3단계: 채팅 참여

• "채팅 참여" 버튼으로 실시간 채팅 시작

• 모바일 채팅도 지원


4단계: API 테스트

• IntelliJ의 api-test.http 파일로 API 테스트

• 로그인 → 방송 생성 → 채팅 → 방송 종료 전체 플로우 확인
